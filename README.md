# WebRTC Real-Time Communication Demo

A simple demo demonstrating how WebRTC works for real-time communication.

## Setup

1. Clone the repository.
2. Initialize the project and install dependencies:

   ```bash
   npm init -y
   npm install express dotenv
   ```

3. Get your API key from the [OpenAI API Platform](https://platform.openai.com/api-keys) and add it to your `.env` file.

4. Start the development server:

   ```bash
   npm run dev
   ```
